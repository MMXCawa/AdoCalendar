# 更新日志 / Changelog

本项目遵循语义化版本格式的 `MAJOR.MINOR.PATCH` 编号。

This project uses `MAJOR.MINOR.PATCH` version numbering.

## 0.0.16

- 对约一年前由作者编写的原 Python 版 ADOCalendar 进行完全重写，使用 Zamak 重新实现应用。
- 这是一次使用 Zamak 与 AI Agent 协作重写既有应用的实践。
- 将用户可见文本集中到独立的简体中文和英文语言模块。
- 在“关于”页面增加语言切换；日期、运势、宜忌、谱面信息和记录预览随语言更新。
- 保持单文件、无控制台 Windows 打包方式。

- Completely rewrote the original Python ADOCalendar, written by the author about a year ago, and reimplemented the application in Zamak.
- This release is a practical exercise in rewriting an existing application with Zamak and an AI Agent.
- Extracted user-facing strings into separate Simplified Chinese and English localization modules.
- Added an About-page language switch; dates, fortune, recommendations, level details, and record previews follow the selected language.
- Retained single-file, no-console Windows packaging.

## 0.0.15

- 当前仓库的初始 Zamak GUI 版本基线。
- 包含每日运势、每日谱面推荐、主题、关于页面和记录保存等功能。

- Initial Zamak GUI baseline represented in this repository.
- Includes daily fortune, daily level recommendations, themes, an About page, and record saving.
